# 🚗 Egyptian Used Car Price Predictor & Market Analyzer

An interactive web application built with **Streamlit** and **Machine Learning** to estimate used car prices in Egypt, calculate monthly installments, evaluate vehicle condition, and estimate fuel efficiency.

## ✨ Features
* 💰 **ML Price Prediction:** Predicts car price based on brand, model, year, mileage, engine capacity (CC), transmission, and condition.
* 📊 **Market Insights:** Interactive charts for average market prices across top brands in Egypt.
* 📉 **Installment Calculator:** Custom loan calculator based on down payment, tenure, and bank interest rate.
* ⛽ **Fuel Efficiency Estimator:** Calculates fuel consumption per 100 KM based on engine CC and fuel type.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Machine Learning:** Scikit-Learn / Joblib
* **Data Processing:** Pandas, NumPy
